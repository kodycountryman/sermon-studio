# Sermon Studio roadmap

The user's selected features are organized into six agreed phases. Phases 1 through 6 have been implemented in local preview; publication is a separate action.

1. Autosave, recovery and dependable storage: #1 autosave/crash recovery, #2 version history, #40 offline preparation and queued syncing.
2. Document organization: #7 clickable outline, #8 whole-section reordering, #19 scratchpad, #20 anchored comments/reminders.
3. Assistant personalization and durable research: #4 pinned passage research, #16 editable assistant theology/voice/rules and audience presets, #17 connected personal stories with themes, delivery estimates, privacy and usage history. Ordinary assistant histories remain temporary while the sermon is open.
4. Timing, openings and closings: #6 estimated preaching time and section estimates with adjustable pace/pauses, #25 callback finder, #28 opening workshop, #29 closing workshop. Workshop suggestions require explicit application to a captured selection, with a checkpoint first.
5. Finished-sermon outputs: #9 Word and PDF export preserving colors/highlights/font size/0pt paragraph spacing with manuscript and print-friendly layouts; #30 editable slide-point queue from yellow highlights, linked to source passages and flagged when sources change; #36 small-group questions, leader notes and responses; #37 selectable takeaway packages (summary, devotional, discussion questions, social captions). All outputs must use one consistent manuscript snapshot and record the producing sermon version. Slide deck export can follow later.
6. Long-term library and mobile use: #34 search title/text/Scripture/themes/audience/stories, #38 post-sermon reflections including actual duration and delivery changes, #41 tablet/phone optimization for touch selection, keyboard overlap and floating controls. Mobile usability is checked throughout; dedicated final pass here.

See phase documentation for implementation details and verification. Do not infer authorization to deploy from implementation requests.
