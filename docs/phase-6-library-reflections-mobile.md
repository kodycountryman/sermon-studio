# Library, delivery reflections and mobile editing

Saved Sermons now searches title, manuscript text, full-book Scripture references, explicit theme tags, audience and linked story titles/text. Search terms combine, with selectable field, audience/theme filters, recent/title/relevance sorting, matched-field labels and a result count. HTML is parsed as text rather than searched as markup. Legacy sermons remain searchable without new metadata. Searches include linked inserted story passages, not unrelated stories or assistant histories. Theme tags are comma separated in Preparation → Reflections.

Preparation → Reflections records multiple deliveries per sermon: date, venue, optional actual minutes, what connected, changes for next time and follow-up responses. A saved source checkpoint records the manuscript, audience and timing settings. Each entry compares actual duration with that snapshot's estimate. Reflections and tags use the same preparation storage, crash recovery, database syncing and version restoration as other notes. Entries are deliberately historical; add a new entry for another delivery. Reflections do not alter manuscript text, word count or speaking pace automatically.

Phone Fit width reflows the page at full font size, while explicit zoom percentages retain page zoom. Toolbar and preparation controls have larger touch targets. Inputs use 16px mobile fonts; fullscreen HUD wraps and remains scrollable. The document, Assistant and Outputs panels follow Visual Viewport height/offset changes so keyboard opening can reduce usable panel height. Listener cleanup handles resize, scroll and unmount. Safe-area insets support floating controls. Floating launch/count overlays hide when a phone preparation panel obscures the document, and the assistant launch hides while its panel is open. The expanded HUD no longer covers preparation tabs. The navigation toggle has an accessible name and expanded state.

Verification: 35 tests pass, covering search scope/filter combinations, legacy metadata, linked story content, reflection duration validation, and reflection/tag recovery, database synchronization and version restoration. Isolated localhost browser checks confirmed saving a 3.5-minute reflection against a 2.2-minute estimate, theme tags and reflection recovery on normal refresh, Scripture/theme search results, and phone (390×844) and tablet (768×1024) layouts. The Assistant fit within the phone viewport with a readable reflowed document and reachable composer. Production build and whitespace checks pass; existing PDF evaluation and bundle-size warnings remain. Physical touch handles and native on-screen keyboard behavior still warrant an actual-device check; responsive browser resizing does not simulate a real keyboard. No deployment was performed.
